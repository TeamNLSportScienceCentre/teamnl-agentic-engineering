# Handoffs

Beknopte, geschoonde verslagen per werksessie: wat er is gedaan en gecontroleerd,
welke keuzes en open punten er zijn, wat de beperkingen zijn en wat de volgende
stap is. Een nieuwe sessie begint met de nieuwste handoff en het actieve plan.

- Naam: `YYYY-MM-DD-HHMM-onderwerp.md`.
- Format: `.agents/skills/teamnl-agentic-engineering-skill/assets/templates/handoff.md`.
- Handoffs mogen in Git en blijven bewaard zolang het project bestaat.
- Een handoff bevat nooit secrets, persoonsgegevens, echte datarijen, ingevoerde
  credentials of ruwe uitvoerlogs.
- Een goedgekeurde keuze staat ook in `docs/decisions.md`. Een handoff is
  geschiedenis, een beslissing is de actuele stand.
